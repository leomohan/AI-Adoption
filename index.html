Companion tools to the book

Instruments for putting the book to work.

The book argues that enterprise AI succeeds as an organizational change, measured and governed with the same rigor as any other strategic program. These tools let you run that discipline on your own program — score where you stand, and track where the value is coming from.

Four tools, one for each appendix

Appendix A

AI Adoption Maturity Assessment

Fifty questions across five weighted dimensions. Get a composite maturity score, a dimension radar, and the two areas to focus on next.

Open the assessment Appendix B

Executive Dashboard

An editable board for reporting program health, value delivered, and leading indicators. Opens as a worked example; enter your own numbers and export it.

Open the dashboard Appendix C

AI Agent Reporting Templates

A monthly report for each AI agent — usage, quality, incidents, governance controls, and lifecycle recommendation. Switch between agents and export the board.

Open the reports Appendix D

Value Realization Framework

An ROI calculator built on the economics chapter — total cost of ownership, benefit attribution, a computed investment J-curve, sensitivity analysis, and a planned-vs-actual value tracker.
